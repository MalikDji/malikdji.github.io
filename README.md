# Portfolio de Malik Djilali

Site intégralement en français, en HTML, CSS et JavaScript. Aucun outil de compilation nécessaire.

## Aperçu
Décompressez cette archive et ouvrez `index.html` dans votre navigateur. Conservez tous les fichiers dans le même dossier.

## Modifier le contenu
Le fichier `profile.js` regroupe les textes, les expériences, les compétences, les formations et les liens. `index.html` contient la structure, la synthèse des compétences et l’étude de cas ; `styles.css` définit le design ; `script.js` affiche les données et gère la navigation.

Le contenu professionnel a été repris du CV fourni. La période chez Dushow est affichée « Juin 2025 – fin 2025 », selon la précision fournie par Malik. Le projet de fin d’études RDS/FSLogix est présenté à partir du mémoire fourni. Aucune certification supplémentaire n’a été inventée. Le niveau C1 en anglais est celui déclaré dans le CV.

Les coordonnées affichées sont l’adresse e-mail et le profil LinkedIn fourni. Le CV joint est inclus sans modification dans `assets/cv-malik-djilali.pdf` et téléchargeable depuis l’accueil. Les postes recherchés et la disponibilité immédiate ont été précisés par Malik.

## Publication sur GitHub Pages
1. Depuis le compte GitHub `MalikDji`, créez un dépôt public nommé `malikdji.github.io`.
2. Déposez le contenu de cette archive directement à la racine du dépôt, sans dossier parent. Ne déposez pas l’archive ZIP elle-même.
3. Enregistrez les fichiers sur la branche `main`.
4. Dans **Settings → Pages**, choisissez **Deploy from a branch**, puis **main** et **/(root)**. Cliquez sur **Save**.
5. Une fois la publication terminée, ouvrez **Visit site** depuis les paramètres Pages.

Le fichier `.nojekyll` désactive le traitement Jekyll. L’adresse attendue pour ce dépôt est `https://malikdji.github.io/` ; elle ne sera active qu’après publication.

Si ce dépôt existe déjà, vérifiez son contenu avant toute modification. Vous pouvez aussi utiliser un dépôt `portfolio` : les chemins relatifs des fichiers fonctionnent avec une adresse de type `https://malikdji.github.io/portfolio/`.

Documentation officielle :

- https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
